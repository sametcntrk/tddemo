AWS Core Services Demo

yükleniyor…

Elastic Load Balancing (ALB) — dağılım testi —

N adet istek atar ve hangi instance/AZ'nin cevap verdiğini gösterir. Target group'ta stickiness kapalı olmalı. "Bu instance'ı unhealthy yap" ile /health 503 döner; ALB birkaç health check sonra trafiği diğer hedeflere kaydırır.

Amazon RDS —

Bağlanır, sürümü okur, demo_notes tablosunu oluşturur. Her kayıtta hangi instance'ın yazdığı tutulur.


    

  


  
  

    
Amazon S3 —

    
Dosya yükle (veya boş bırakıp test notu yaz). Linkler 5 dk geçerli presigned URL.

    

      
      
      
    

    

  


  
  

    
Amazon DynamoDB —

    
PutItem + Scan. Tablo partition key'i DDB_PK (varsayılan pk, String).

    

      
      
      
    

    

  


  
  

    
ElastiCache (Redis/Valkey) —

    
Paylaşılan sayaç — farklı instance'lardan artırınca aynı değeri görürsün (session/cache paylaşımı).

    

      
      
    

    

  


  
  

    
Amazon SQS —

    
Mesaj gönder, sonra al (alınan mesajlar kuyruktan silinir).

    

      
      
      
    

    

  


  
  

    
Amazon SNS —

    
Topic'e publish eder. E-posta aboneliği ekleyip onayladıysan mail gelir; SQS aboneliği varsa mesaj kuyruğa da düşer (fan-out).

    

      
      
    

    

  


  
  

    
Amazon EFS —

    
Ortak dosya sistemine satır ekler. Tüm instance'lar aynı dosyayı görür (farklı AZ'ler dahil).

    

      
      
    

    

  


  
  

    
Secrets Manager / SSM Parameter Store —

    
IAM rolüyle secret/parametre okur; değer maskelenir. Kodda hiç kimlik bilgisi yok — instance profile kullanılır.

    

    

  


  
  

    
CloudWatch + Auto Scaling —

    
Özel metrik gönder (CoreDemo/DemoClicks) veya CPU yükü üret: ASG'de CPU %50 target tracking varsa birkaç dakika içinde yeni instance açılır.
